# MarkerWalk 0.1.0

The first public release turns an explicit cemetery survey manifest and local photo folder into a
reviewable coverage audit and offline revisit packet.

Highlights:

- missing marker/view combinations and missing/unreferenced file evidence;
- retained field-attempt notes without treating attempts as coverage;
- exact small-survey routes with an honest bounded heuristic for larger visits;
- JSON, CSV, Markdown, SVG, and script-free HTML outputs;
- no accounts, uploads, image recognition, telemetry, or runtime dependencies.

MarkerWalk routes use an obstacle-free local metre grid. They are planning aids, not field-safety or
accessibility guarantees.
