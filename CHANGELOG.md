# Changelog

All notable changes follow Keep a Changelog and Semantic Versioning.

## [0.1.0] - 2026-08-30

### Added

- Strict schema-1 survey manifests with contained relative paths and explicit field-attempt history.
- Offline coverage reconciliation for missing views, missing referenced files, and unreferenced
  local images.
- Proven shortest revisit routes for up to 14 incomplete markers and clearly labelled deterministic
  heuristic routes above that bound.
- Stable JSON, CSV, Markdown, standalone SVG, and script-free HTML field packets.
- Cross-platform CI, release packaging, synthetic examples, and a one-command local release gate.
