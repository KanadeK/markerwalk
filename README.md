# MarkerWalk

MarkerWalk is an offline photo-coverage auditor and revisit-route planner for cemetery and
local-history survey volunteers. The executable implementation is currently being built against
the checked-in [v0.1 specification](docs/spec.md).

MarkerWalk does not identify inscriptions, upload photos, replace cemetery records, or promise
that an obstacle-free Euclidean route is safe or accessible.
